# HTML en CSS — periode 1

Dit is je werkmap voor de hele module. Je gebruikt **één repository**. Werk in VS Code en bekijk je HTML in de browser.

## Beginnen

1. Open je eigen module-repository in VS Code.
2. Open de map van de les in `periode-1/`.
3. Lees de les en oefening in EduInsights. In de versie met bronbestanden open je ook het opgegeven bestand bij **Bronnen**.
4. Maak alleen de HTML- en CSS-bestanden die de opdracht vraagt. Soms staan de startbestanden al klaar.
5. Sla op en controleer in de browser. Maak een commit, push en controleer je bestanden op GitHub.

De mappen staan al klaar. Als een opdracht zegt dat je een nieuwe lesmap op het bureaublad moet maken, gebruik je de bestaande lesmap hier. De map `periode-1` is de periode-map uit de oorspronkelijke lessen.

## Zo blijft je werk bij elkaar

- Ga in hetzelfde bestand verder als de opdracht dat aangeeft.
- Gewone opdrachten staan direct in de lesmap, tenzij de les een projectmap noemt.
- De bestaande extra opdrachten staan in `extra/`. Zo blijven bijvoorbeeld twee verschillende bestanden `structuur.html` gescheiden.
- De map `hulpmiddelen/` bevat bestaande demonstraties. De oefensites voor boxjes, lijsten en tabellen staan bij hun les.
- Voor oefeningen in een meegeleverde oefensite voer je de antwoorden in de browser in. De software slaat die niet automatisch in GitHub op. Laat je resultaat aan de docent zien voordat je het venster sluit.

Les 7 en les 17 zijn de afzonderlijke toetsmomenten en hebben hier geen map. In les 16 werk je verder in de map van een eerdere opdracht of in je bestaande project.

De template bevat de startbestanden en beelden uit het lesmateriaal. Bestanden die je zelf moet leren aanmaken, zijn nog niet ingevuld.
